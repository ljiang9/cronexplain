# cronexplain

用人话解释 cron 表达式，并算出接下来几次执行时间。纯标准库、纯本地，零依赖。

## 安装

无需安装，Python 3.10+ 直接运行：

```bash
cd cronexplain
python3 -m cronexplain "0 9 * * 1-5"
```

## 用法

```bash
# 基本：解释 + 接下来 5 次执行时间
python3 -m cronexplain "0 9 * * 1-5"
# 表达式：0 9 * * 1-5
# 含义：每个工作日 09:00 执行
# 从 2026-10-05 04:35 起，接下来 5 次执行：
#   2026-10-05 09:00 周一
#   2026-10-06 09:00 周二
#   ...

# 快捷写法
python3 -m cronexplain "@daily"
python3 -m cronexplain "@hourly"

# 指定起始时间 / 次数
python3 -m cronexplain "*/15 * * * *" --from "2026-10-05 12:00" -n 3

# JSON 输出（给脚本用）
python3 -m cronexplain "0 0 29 2 *" --json
```

## 支持的语法

| 写法 | 说明 |
|---|---|
| `*` | 任意值 |
| `1-5` | 范围 |
| `*/15`、`0-30/10` | 步长 |
| `1,15` | 列表 |
| `JAN`-`DEC`、`MON`-`SUN` | 英文名称（大小写不限） |
| `@yearly` `@monthly` `@weekly` `@daily` `@hourly` | 快捷写法 |
| `0` 和 `7` | 在"周"字段都表示周日 |

## 真实 cron 语义

"日"和"周"两个字段**都受限时是 OR 关系**（满足其一即执行），这是很多人踩过的坑：

```bash
python3 -m cronexplain "30 8 1 * MON"
# 含义：每月第1天或周一（满足其一即执行） 08:30 执行
```

## 算法说明

找"接下来几次"用的是**逐分钟推进**：从起始时间的下一分钟开始，一分钟一分钟往后检查是否命中，
整月都不在月份集合里时直接跳到下月 1 日（否则 `0 0 29 2 *` 这种四年一次的表达式要空转数百万分钟）。
默认向前搜索 4 年（覆盖闰日周期），分钟精度。

## 诚实说明

- **分钟精度**：不支持带秒的 6 字段 cron（如 Quartz 格式），多出来的字段会报"需要 5 个字段"。
- **时区**：按运行机器的本地时间计算，不做夏令时跳变特殊处理（跳变的那一分钟可能多算/少算一次，属启发式）。
- 月/日名称只认英文缩写；`L`、`W`、`#` 等扩展语法不支持，会明确报错而不是猜。
- 解释文字是启发式生成，复杂组合可能读起来别扭，但"接下来几次"是逐分钟精确计算的，以时间为准。

## 退出码

- `0`：正常
- `1`：表达式非法（中文报错）或参数错误
